# 环炮防线

竖屏环形炮塔肉鸽的可玩原型。炮塔钉在基地外圈上自动旋转、自动锁定最近的敌人开火。玩家只能拖动或轻点来加速、反向，让炮口对着最密的一路敌人。每波结束后三选一升级，基地生命归零则结算存活波次。

## 为什么是 HTML5 Canvas，而不是 Cocos

目标形态是 Cocos Creator 导出的微信小游戏。这个环境里没有 Cocos Creator 编辑器或 CLI（`cocos` 不在 PATH 中），因此没有阻塞在安装完整编辑器上。

本原型用 Vite + TypeScript + Canvas 实现同一套循环。模拟层不依赖 DOM，渲染和指针只在 `src/main.ts` 与 `src/render/`。以后迁到 Cocos 时，可以把 `src/systems/` 里的模块收成组件或系统：

| 模块 | 职责 |
| --- | --- |
| `systems/ring.ts` | 环的巡航转速、拖动甩动、反向、转速上限 |
| `systems/input.ts` | 单指拖动 / 轻点手势 |
| `systems/enemies.ts` | 敌人沿直线走向基地；飞行兵带轻微横移；分裂兵死亡后拆成两只 |
| `systems/targeting.ts` | 炮塔自动索敌、扇形分裂弹 |
| `systems/projectiles.ts` | 子弹命中、爆炸、冰冻、穿透、连锁闪电 |
| `systems/pool.ts` | 子弹、敌人、粒子、金币的对象池 |
| `systems/waves.ts` | 波次组成、边缘出生点、精英波、第二进攻方向 |
| `systems/upgrades.ts` | 炮塔 / 效果 / 机制三选一，以及数值叠加 |
| `systems/particles.ts` `systems/pickups.ts` | 粒子与金币吸附 |
| `game.ts` | 把上面的系统串成一局 |

## 运行

```bash
npm install && npm start
```

浏览器打开终端里给出的本地地址（默认 http://localhost:5173 ）。手机或窄窗口即是竖屏。无头冒烟测试：

```bash
npm run smoke
```

## 操作

- 按住拖动：沿基地绕圈，环会跟上手指并保持甩出去的转速
- 轻点：反向旋转
- 键盘：`A` / `D` 或左右方向键加速，空格反向，失败后 `R` 重开

## 这一局里有什么

- 中央基地与生命值。敌人走到基地会扣血并消失。
- 开局 1 座炮塔，沿环自动转，范围内自动打最近的敌人。
- 敌人从屏幕外沿边缘走进来，后期会从两个方向夹击。
- 第 5、10、15… 波是精英波：一只高血量精英，加上小怪，并且从四面八方出现。
- 敌人种类随波次出现：步兵、迅捷、重装、分裂、飞行。
- 波次之间三选一：加装炮塔、射速 +20%、射程 +15%、分裂射击（1 发变 3 发，之后最多 5 发）、爆炸、冰冻、穿透、连锁闪电、最大转速 +50%、击杀回血、每约 10 秒全屏冲击、金币掉落。
- 选过金币后，敌人会掉金币；升级界面若金币够，可以再买一次升级。
- 失败界面显示存活波次、击杀和用时，可以重开。
- 子弹走对象池，避免一波里大量 `new`。

原型把单波压短了，方便几分钟内打完几波。完整 5–8 分钟的节奏需要再调数量和血量，系统本身已经接上。
